# CliniqFlow — Documentação do Produto

> ⚠️ Projeto de portfólio desenvolvido para prática das competências de Product Owner.  
> Todos os cenários, personas e dados foram simulados com base em pesquisa de mercado e referências do setor de saúde.

---

## 📌 Visão geral

**CliniqFlow** é uma plataforma B2B de gestão operacional para clínicas e consultórios de pequeno e médio porte. O projeto nasceu de um problema real do setor: a maioria das clínicas ainda opera com agendamentos manuais, prontuários em papel e nenhuma visibilidade sobre indicadores operacionais.

## 💡 Principais aprendizados

- Requisitos com implicações regulatórias (LGPD/CFM) precisam de refinamento extra antes de entrar no DoR
- O gestor da clínica não precisa de mais tecnologia — precisa de visibilidade operacional simples e imediata
- OKRs bem escritos medem outcome, não entrega de feature
