# Definition of Ready (DoR) — CliniqFlow

Os itens do backlog devem atender aos seguintes critérios antes de serem selecionados para uma Sprint Planning:

- [ ] **Claro:** O objetivo da User Story está compreensível para todo o time.
- [ ] **Estimado:** O time de desenvolvimento pontuou a complexidade da tarefa.
- [ ] **Critérios de Aceite:** Os cenários de teste mínimos estão descritos.
- [ ] **Dependências:** O item não possui impedimentos ou dependências externas ativas.
- [ ] **Valor:** O valor de negócio para o usuário ou cliente está evidente.
