# Definition of Done (DoD) — CliniqFlow

Uma User Story é considerada "Concluída" (Done) quando atende aos seguintes requisitos:

- [ ] **Desenvolvimento:** O código foi escrito seguindo os padrões do projeto.
- [ ] **Revisão:** Passou por Code Review / Aprovação de outro desenvolvedor (se aplicável).
- [ ] **Testes:** Os critérios de aceite foram validados com sucesso.
- [ ] **Design:** A interface reflete o que foi desenhado no protótipo.
- [ ] **Homologação:** O Product Owner (PO) validou e aceitou a entrega.
